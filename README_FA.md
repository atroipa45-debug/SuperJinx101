# پنل Rebecca روی Railway + قابلیت نمایندگی

## نکته مهم
قابلیت نمایندگی در سورس رسمی Rebecca از قبل وجود دارد؛ این بسته برای استقرار آن روی Railway است و قابلیت Reseller را از صفر بازنویسی نمی‌کند. هنگام Build، سورس رسمی از GitHub دریافت می‌شود.

مخزن رسمی: https://github.com/rebeccapanel/Rebecca

## فایل‌های بسته
- `Dockerfile`: سورس رسمی را دریافت می‌کند و داشبورد React و بک‌اند Go را می‌سازد.
- `railway-start.sh`: پورت اختصاصی Railway را می‌خواند، مهاجرت دیتابیس را اجرا می‌کند و سرویس را بالا می‌آورد.

## استقرار
1. ZIP را استخراج کن؛ فایل‌ها را مستقیم در ریشه یک مخزن GitHub قرار بده.
2. Commit کن و مخزن را به Railway متصل کن: **New Project → Deploy from GitHub Repo**.
3. بعد از اتصال، صبر کن Build و Deploy کامل شود.
4. در Railway → **Volumes** یک Volume بساز و Mount Path را روی `/var/lib/rebecca` قرار بده.
5. در **Networking** برای سرویس یک دامنه بساز.
6. دامنه را باز کن و به مسیر `/dashboard/` برو.

Railway مقدار `PORT` را خودش تعیین می‌کند؛ آن را دستی ثابت نکن.

## ساخت نماینده (Reseller)
بعد از ورود با حساب ادمین اصلی:

1. از منوی پنل وارد **Admins** شو.
2. **Add admin** را انتخاب کن.
3. نام کاربری و رمز عبور نماینده را تعیین کن.
4. نقش **Reseller** را انتخاب کن.
5. `data_limit` را برای سقف حجم/داده و `users_limit` را برای حداکثر تعداد کاربران نماینده تنظیم کن.
6. حساب را ذخیره و فعال کن.

نماینده با حساب خودش وارد پنل می‌شود و فقط کاربران خودش را مدیریت می‌کند؛ به بخش‌های حساس سیستمی دسترسی کامل ندارد.

## ساخت اکانت برای مشتری
نماینده از بخش **Users → Create user** می‌تواند موارد زیر را تعیین کند:
- نام کاربری
- تاریخ انقضا / مدت اعتبار از طریق تاریخ انقضا
- سقف حجم
- سرویس و inbound مجاز
- محدودیت IP
- در صورت نیاز Auto Renew

## نگه‌داری اطلاعات
Volume را روی `/var/lib/rebecca` تنظیم کن تا دیتابیس SQLite و فایل‌های مربوطه با Deploy مجدد از بین نروند. برای استفاده جدی، از دیتابیس پایدار و نسخه پشتیبان نیز استفاده کن.

## محدودیت‌ها و هشدارها
- این بسته هنوز روی پروژه واقعی Railway Build/Deploy نشده است؛ پس سازگاری نهایی تضمین‌شده نیست. اگر Build شکست خورد، لاگ کامل Build را بفرست.
- پنل مدیریت به‌تنهایی تضمین نمی‌کند ترافیک VPN روی Railway کار کند. برای سرویس‌دهی واقعی معمولاً باید نودهای Xray جداگانه روی VPS اجرا و از داخل پنل متصل شوند.
- برای تثبیت نسخه، مقدار `REBECCA_REF` در ابتدای Dockerfile را به یک Tag معتبر تغییر بده، نه اینکه همیشه از `master` بسازی.
- قبل از ارائه دسترسی به نماینده‌ها، رمز قوی انتخاب کن و سطح دسترسی و سقف حجم آن‌ها را بررسی کن.
- پروژه رسمی تحت مجوز AGPL-3.0 منتشر شده است؛ شرایط مجوز را در مخزن رسمی بخوان.
